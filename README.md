# deckDen 
is a full-stack web app where trading card game players can build, save, and share decklists across multiple games — starting with Yu-Gi-Oh, Pokémon, and Union Arena. Users create public profiles to showcase their decks, search a unified card database, and browse builds from other players in the community.

Built with Next.js, TypeScript, and Tailwind CSS on the frontend, FastAPI and PostgreSQL on the backend, deployed on Vercel with GitHub Actions CI/CD.
